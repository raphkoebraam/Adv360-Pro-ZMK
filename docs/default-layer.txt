# has Shift mod-morph: Shift+# sends Cmd+Shift+4 (screenshot).
^ has Shift mod-morph: Shift+^ sends Cmd+Shift+5 (recording).
HYP = Hyper (Ctrl+Alt+Cmd+Shift).


LEGEND
──────

Scr3  = Cmd+Shift+3  (macOS full screenshot)
Scr4  = Cmd+Shift+4  (macOS area screenshot)
Scr5  = Cmd+Shift+5  (macOS screen recording)
Lock  = Ctrl+Cmd+Q   (macOS lock screen)
Mod   = Momentary Mod/BT layer (layer 3)
Curs  = Momentary Cursor layer (layer 1)
Num   = Momentary Number layer (layer 2)
Fn    = Momentary Function layer (layer 5)
Sym   = Momentary Symbol layer (layer 4)
Sys   = Momentary System layer (layer 6)
Low   = Momentary Lower layer (layer 7)
HYP   = Hyper (Ctrl+Alt+Cmd+Shift)
LSh   = Left Shift (dedicated)
RSh   = Right Shift (dedicated)
Ctrl  = Hold modifier (LCTL / LCTL)
Alt   = Hold modifier (LALT / LALT)
Cmd   = Hold modifier (LGUI / LGUI)
Shft  = Hold modifier (LSFT / LSFT)
